instalar dependências:
    docker run --rm -v "$PWD:/app" -w /app node npm install

dar build via docker:
    docker run --rm -v "$PWD:/app" -w /app node npm run build

rodar via npm run dev:
    docker run --rm -it -v "$PWD:/app" -w /app -p 3000:3000 node npm run dev -- --host 0.0.0.0

    ou para deixar em segundo plano:

    nohup docker run --rm --name vite-lista-tarefas -v "$PWD:/app" -w /app -p 3000:3000 node npm run dev -- --host 0.0.0.0 > vite.log 2>&1 &

Para a etapa CI: etapa de testes:
    instalação do executor dos testes (vitest) e da biblioteca que ajuda testar componentes (@vue/test-utils):
        npm install -D vitest @vue/test-utils
    adicionar no 'scripts' do package.json:
        "test": "vitest run"
    criar:
        teste/FormTarefa.test.js
        tests/setup.js
    instalar:
        npm install -D jsdom
    em vite.config.mjs, adicione ao 'return':
        test: {
            environment: 'jsdom',
            css: true,
            setupFiles: './tests/setup.js',
            server: {
                deps: {
                    inline: ['vuetify'],
                },
            },
        },
    rodar pra testar e depois colocar no deploy.yml:
        npm run test
