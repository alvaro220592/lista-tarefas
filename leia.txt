instalar dependências:
    docker run --rm -v "$PWD:/app" -w /app node npm install

dar build via docker:
    docker run --rm -v "$PWD:/app" -w /app node npm run build

rodar via npm run dev:
    docker run --rm -it -v "$PWD:/app" -w /app -p 3000:3000 node npm run dev -- --host 0.0.0.0

    ou para deixar em segundo plano:

    nohup docker run --rm --name vite-lista-tarefas -v "$PWD:/app" -w /app -p 3000:3000 node npm run dev -- --host 0.0.0.0 > vite.log 2>&1 &
